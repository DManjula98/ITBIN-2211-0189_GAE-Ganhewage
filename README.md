# 🎓 Study Hub Mobile App

**Study Hub** is a mobile application designed to help students manage their studies effectively.  
It provides a complete self-study management experience — allowing students to **create timetables**, **organize tasks**, and **calculate grades** all in one place.  

---

## 📱 Features

### 🕒 Timetable Manager
- Add, edit, and delete study sessions easily  
- Choose start and end times for each task  
- Highlight tasks with colors for better visualization  
- View all scheduled tasks in a simple and organized layout  

### ✅ To-Do List
- Create and manage academic tasks  
- Mark tasks as complete or delete them when finished  
- Stay organized and boost productivity  

### 🧮 Grade Calculator
- Enter marks for each subject or assignment  
- Instantly calculate **total marks, average**, and **final grade**  
- Simple and accurate performance tracking

## 🧰 Tech Stack

| Component | Technology Used |
|------------|----------------|
| Language | **Java** |
| Database | **Google Firestore** |
| Platform | **Android (Mobile)** |
| UI Design | **XML (Android Studio)** |

---

## ⚙️ App Structure

- `timetable.xml` → Displays daily schedule  
- `task.xml` → Shows individual task cards  
- `edittask.xml` → Page to add or update tasks  
- `adapter/` → Handles displaying data in list views  
- `model/` → Manages data structure for tasks and grades  

---

## 🚀 How It Works

1. **Timetable Creation**  
   Students can add study tasks with start/end times, assign colors, and view them on their daily timetable.  

2. **To-Do List Management**  
   A simple interface for adding, viewing, and deleting tasks to keep track of academic activities.  

3. **Marks Calculation**  
   Add marks for subjects and get instant calculations for total, average, and grade.
